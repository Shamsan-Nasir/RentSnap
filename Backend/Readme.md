# RentSnap Backend

Backend API for RentSnap, a SaaS rental inventory and booking management platform.

## Technology Stack

- Python
- Django 5.2 LTS
- Django REST Framework (planned)
- PostgreSQL (planned)
- JWT Authentication (planned)

## Local Setup

1. Create a Python virtual environment.
2. Activate the virtual environment.
3. Install dependencies with `python -m pip install -r requirements.txt`.
4. Run migrations using `python manage.py migrate`.
5. Start the development server with `python manage.py runserver`.

## Project Scope

The MVP covers shop management, product inventory, customer records, rental bookings, stock availability, dispatch, returns, payments and basic operational reporting.
